# skins

Put or symlink your own osu! stable skin folders here (git-ignored).
Example: `ln -s ~/.local/share/osu-wine/osu\!/Skins/MySkin skins/MySkin`

The game does not scan this folder by itself; use `aimless --skins=skins` (or set `skins_dir` in settings.ini),
or import with `aimless import MySkin.osk`.
