# Contributing

- Keep it **light**: no heavy dependencies, no per-frame allocations, measure before and after.
- Keep the code small and readable C99.
- AI-assisted contributions are welcome. Mention it in the PR and make sure you understand and tested the code.
- Never add osu! source code or assets. Everything here must be original or properly licensed.
- No online features, scoreboards, or anything that could be used for cheating in real osu! play.

Ideas: sliders, spinners, hitsounds, song select, config file, Wayland/X11 testing, profiling on integrated GPUs.
